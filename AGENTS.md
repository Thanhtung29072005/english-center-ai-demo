
# English Center AI Demo

## Project
English Center Management System

## Objective
Demonstrate multi-agent software engineering
using Hermes Agent.

This is an existing completed project.

DO NOT rebuild the application from scratch.

## Technology
Backend: Java Spring Boot + Maven
Frontend: Vite + JavaScript
Database: MySQL

## Workspace
/workspace/english-center-ai-demo

## Agent Responsibilities

PM:
- Analyze requirements and Jira backlog
- Define acceptance criteria
- Track task progress

Architect:
- Analyze existing system architecture
- Identify dependencies and risks

Designer:
- Review existing UI/UX
- Propose improvements when relevant

Coder:
- Implement approved changes
- Write automated tests

Reviewer:
- Review changes independently
- Identify bugs and security issues

Tester:
- Design test cases
- Execute automated tests
- Report actual results

DevOps:
- Prepare local build/test environment
- Maintain safe Docker configuration

## Workflow

1. Read existing source code
2. PM analyzes selected module
3. Architect reviews technical approach
4. Owner approves the task
5. Coder implements changes
6. Reviewer reviews code
7. Tester runs tests
8. Coder fixes failures if necessary
9. Hermes produces a final report

## Restrictions

- Never rewrite the entire application
- Never delete existing functionality
- Never modify the original project
- Never expose secrets
- Never use production database credentials
- Never run destructive database commands
- Never push code without approval
- Never claim tests passed without running them
- Work on one implementation task at a time
